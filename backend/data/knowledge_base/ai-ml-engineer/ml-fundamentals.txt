Supervised vs Unsupervised Learning

Supervised learning trains a model on labeled data, learning a mapping from input features to known output labels, and is used for tasks like classification and regression. Unsupervised learning works with unlabeled data to discover structure, such as clustering (grouping similar points, e.g., k-means) or dimensionality reduction (e.g., PCA, which projects data onto directions of maximum variance). Semi-supervised learning combines a small amount of labeled data with a larger pool of unlabeled data, which is useful when labeling is expensive.

Bias-Variance Tradeoff

A model's generalization error can be decomposed into bias, variance, and irreducible error. High bias means the model is too simple to capture the underlying pattern (underfitting); high variance means the model is too sensitive to the specific training data and fails to generalize (overfitting). Increasing model complexity typically reduces bias but increases variance, and vice versa. Techniques like regularization (L1/L2 penalties), cross-validation, and ensembling directly address this tradeoff by constraining model complexity or averaging out variance across multiple models.

Gradient Descent and Optimization

Gradient descent iteratively updates model parameters in the direction that reduces a loss function, scaled by a learning rate. Too large a learning rate can cause divergence or oscillation; too small a learning rate makes convergence slow. Stochastic gradient descent (SGD) updates parameters using a single sample or small mini-batch rather than the full dataset, trading off noisier updates for dramatically faster iterations on large datasets. Adaptive optimizers like Adam maintain per-parameter learning rates based on historical gradients, generally converging faster and more robustly than vanilla SGD for deep learning.

Neural Network Architectures

A feedforward neural network consists of layers of neurons where each neuron computes a weighted sum of its inputs followed by a nonlinear activation function (e.g., ReLU, sigmoid, tanh). Convolutional neural networks (CNNs) use shared, spatially-local filters that make them well suited to image data, since they exploit spatial locality and translation invariance. Recurrent neural networks (RNNs) and their gated variants (LSTM, GRU) process sequential data by maintaining a hidden state across time steps, though they've largely been superseded for many NLP tasks by transformer architectures, which use self-attention to model relationships between all positions in a sequence in parallel rather than sequentially.

Evaluation Metrics for Classification

Accuracy alone can be misleading on imbalanced datasets — a model predicting the majority class every time can have high accuracy while being useless. Precision measures the fraction of positive predictions that are actually correct; recall measures the fraction of actual positives that were correctly identified. The F1 score is the harmonic mean of precision and recall, useful when you need a single number balancing both. The ROC curve plots true positive rate against false positive rate across thresholds, and the area under it (AUC) summarizes overall discriminative ability independent of a specific threshold choice.

Feature Engineering and Preprocessing

Feature engineering — creating, transforming, or selecting input variables — often has more impact on model performance than the choice of algorithm itself. Common techniques include normalization/standardization (scaling features to comparable ranges, important for distance-based and gradient-based methods), one-hot encoding for categorical variables, handling missing values (imputation or explicit missingness indicators), and creating interaction or polynomial features to capture nonlinear relationships that a linear model couldn't otherwise represent.

Retrieval-Augmented Generation (RAG)

RAG combines a retrieval system with a generative language model: rather than relying solely on knowledge baked into the model's parameters at training time, the system retrieves relevant passages from an external knowledge source at inference time and conditions the generation on that retrieved context. This reduces hallucination, allows the knowledge base to be updated without retraining the model, and provides traceability — the retrieved passages can be cited as the source of a generated claim. Key design decisions in a RAG system include the chunking strategy (how source documents are split), the embedding model used to represent text semantically, the choice of vector similarity search (e.g., approximate nearest neighbor methods), and how many retrieved chunks to include in the generation context without exceeding the model's context window or diluting relevance with noise.

Overfitting and Regularization

A model overfits when it captures noise or idiosyncrasies of the training data rather than the underlying generalizable pattern, resulting in strong training performance but poor performance on unseen data. Regularization techniques combat this by discouraging overly complex models: L2 regularization (weight decay) penalizes large weights, L1 regularization encourages sparsity by driving some weights to exactly zero, and dropout randomly deactivates a fraction of neurons during training to prevent co-adaptation. Early stopping — halting training once validation performance stops improving — is another simple but effective regularization technique.
